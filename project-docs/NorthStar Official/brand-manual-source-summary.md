# 2020 Brand Manual source summary

Authoritative source: `project-docs/NorthStar Official/2020 Brand Manual.pdf` (last updated May 2020).

This summary exists to make the implementation traceable. It does not supersede or reinterpret the Brand Manual.

## Page 5 — Typography

- Primary: Raleway regular / italic / bold / bold italic
- Substitution: Montserrat regular / italic / bold / italic bold
- Disclosure: Myriad Pro Condensed
- Header color: `#4F4F54`
- Subheader color: `#A7A9AC`
- Reference sizing for an 8.5 × 11 marketing piece:
  - Title header: 18 minimum–24 maximum
  - Title subheader: 11 minimum–14 maximum
  - Body: 9 default–10 maximum
  - Disclosures/footer: 7.5 default
- The manual states font sizes may vary depending on document size.

## Page 6 — Logo versions

The default corporate identity for this application is the North Star Resource Group logo. The manual provides horizontal and stacked flexibility and separate entity lockups for North Star Consultants, Inc. and North Star Consultants Texas, Inc. Those other entity lockups are not used by this application.

## Page 7 — Logo backgrounds

The manual provides approved logo treatments for:

- Color backgrounds
- Dark backgrounds
- Light backgrounds

The application header uses the dark-background Resource Group treatment.

## Page 8 — Logo guidelines

- Clear space around the logo should be at least the width of the star.
- More whitespace is preferable.
- Do not crowd the logo with nearby text.
- Keep the logo proportionate.
- Do not squish, stretch, or distort the logo.

## Pages 9-11 — Imagery

The manual defines Business, Occupation, and Lifestyle marketing imagery. The current Gap Tool contains no marketing/hero photography, so these requirements are not active implementation surfaces in this revision. They remain required if marketing imagery is introduced later.
